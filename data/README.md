# Data Notes

The files in `data/samples/` are synthetic examples created for this portfolio repository.
They are not APJ source text, client data, OCR output, or manually validated capstone records.

Standard sentence schema:

```text
source_file,page,species_name,sentence
```

Standard trait definition schema:

```text
trait_name,trait_value,trait_type
```

Standard prediction schema:

```text
source_file,page,species_name,sentence,predicted_trait,predicted_value,method
```
